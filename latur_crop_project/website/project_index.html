Project Overview

The Latur Crop Recommendation System uses 15-year historical weather data (2010-2025) from Open-Meteo, ICRISAT district irrigation data, and a multi-factor scoring formula (F = [0.25R + 0.20T + 0.25So + 0.10W + 0.10G + 0.05H + 0.05M] × L) to recommend optimal crops for any tehsil in Maharashtra.

The system is designed to prevent rice over-ranking in water-scarce regions and prioritize water-efficient crops where appropriate.
